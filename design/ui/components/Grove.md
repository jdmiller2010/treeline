# Grove

Your treehouse in the middle and a string out to every family it is strung with: the Strings page's map. Names and numbers are real text in real buttons; the strings and houses are a decorative drawing behind them.

**Consumer provides:** `me` (`name`, `number`), `friends` (each `id`, `name`, `number`, `state`, `href`), `selectedId`, `newIds`, `moreHref`. Build it with `TLGrove.html(options)` from `js/grove.js`; the kit has no React version.

- One drawing, 390 × 470, that scales with its container (max 520px wide, centered). It sets its own `container-type`, so it needs no shell around it, but every screen still sits in `.tl-app` or `.tl-root`.
- **States** are `data-state` on each node, and each has a shape as well as a color, so none depends on color alone: **live** (solid bark string with a leaf), **paused** (quiet house, grey dashed string, pause badge), **wait** (we asked, they have not answered: faint house with a dashed outline, dotted string, clock badge), **ask** (they asked and it is ours to answer: `?` badge on a sun-yellow dotted string).
- Each house takes one of five wash pigments (leaf, sky, petal, sun, bark) from a hash of its name and number, so a family keeps its color. Your own house is the hero treehouse of `illustrations/treehouse.svg` (big canopy, branches, ladder), about twice the size of the others, so it is always plainly yours. The others are short-trunked versions of the connection plate's tree.
- A node is a `button` (at least 61px wide at 360px) named "name, number, state". `data-href` carries where it goes; the app listens for the click. The selected one has `aria-current` and a dashed sun ring. Focus is the standard focus ring.
- **Up to 12 families** (`TLGrove.MAX`). Six or fewer sit on hand-picked spots; from seven, each house is placed on the first spot where it and its name tag overlap nothing and no string runs through another house, the drawing grows taller (580 to 680) and houses and tags shrink a little (`--grove-s`; names are 12px from ten). The leaf on each string slides along it to stay clear of name tags. **From the 13th family the app shows the list instead** (the Map | List switch goes away and a line says why); the kit draws only the first twelve if it is given more. There is no limit on strings themselves.
- The houses are the left treehouse of `illustrations/connection.svg`, path for path, and the strings are its dotted bark line with the hanging leaf, so the map is drawn by the same hand as every plate.
- **A new string** (`newIds`): the line draws itself from your house, the house unfurls where it ends, two leaves drift down. Under reduced motion it simply appears.
- Tags are paper, not text on the drawing: the name is clipped with an ellipsis at 30% of the width and the full name stays in the accessible name. Names are escaped.
- Light from the top-right, pencil line then wash, tokens only: the art direction of a plate (README, "Art direction"). Not a graph: no zoom, no dragging, no physics.
- The Strings page pairs it with a Map | List `SegmentedControl`; the list is the accessible and the many-families view.

## HTML

Exact markup (generated by `TLGrove.html`); see `components/Grove.html` for five strings in every state, a string being made and the empty map.

- **Strings go behind the trees.** Each string runs from your platform to theirs, and the strings layer is masked by every canopy and house, so a line simply disappears behind a tree and ends there: no gap, no dot at the end.
