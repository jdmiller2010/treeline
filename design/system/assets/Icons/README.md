# Icons

Treeline's line icons: 24 × 24 grid, 1.75 stroke, round caps and joins, no fills.

These SVG files are drawn in `ink` (#2a251c) because an `<img>` can't inherit color. In code, use `Treeline.Icon`, which draws the same shapes in `currentColor`. For other inks, recolor the file's `stroke` in your tool.

- `phone`: a rotary phone. Call, on a call
- `phone-incoming` / `phone-outgoing`: the rotary phone with an arrow in or out; call log direction
- `phone-off`: the rotary phone struck through. Offline, missed call, end call
- `bell`: ringing
- `moon` / `sun`: quiet hours / daytime
- `pause`: paused by a parent
- `lock`: blocked call
- `shield-check`: approved, safe
- `leaf`: connected friends
- `ladder`: the treehouse, inviting someone in
- `key`: entering a code
- `home`: household
- `users`: strings (friends' families), and Profile in the account menu
- `book`: the phone book
- `string`: a string between two treehouses (New string connection)
- `clock`: time limits, waiting for approval
- `check`, `close`, `plus`, `chevron-right`: utility
- `chevron-down`: opens a select or a disclosure
- `info`: an information alert or toast
- `alert`: a warning or a failure; alerts and toasts
- `settings`: settings (two sliders), in the account menu
- `log-out`: sign out
- `more`: three dots; a row's or card's "more" menu
- `eye` / `eye-off`: show and hide a password
- `trend-up`: a number going up, in StatTile notes
- `coffee`: a cup with steam, for the "Buy me a coffee" support link
- `mail`: an envelope, for an email link
