# Steps

Where you are in a short setup flow, and how much is left.

**Consumer provides:** `steps` (short names), `current` (1-based), optional `label`.

- **A gust of wind carrying leaves along a line.** The same look as the LeafLoader, used as progress. Each step is one length of the gust: upcoming lengths are a dotted `bark-soft` line with no leaf, the current one is drawn solid `ink-muted` about halfway with a leaf tumbling along it, and a finished one is solid all the way and ends in a leaf that has landed (the leaf of the step you just finished settles once). Each length has its name under it; the current name is ink and bold. With reduced motion the leaf rests on the line instead of tumbling.
- **Under 560px of the Steps' own width** the names fold into one line above the line ("Step 2 of 4: Add a kid") so it never crowds a phone.
- `pinned` makes it stick to the top of the screen on `canvas` (full width, no sideways scroll), with a soft fade underneath, so it stays in view as the form scrolls. Use it on a long setup page; leave it off inside a Sheet.
- For 3–5 steps. Put it at the top of the flow's page, under the AppBar, `space-8` above the content. Back and Next live in the page's actions, not in the steps.
- Steps aren't links: going back is the Back button, so a parent never skips a required step.
